
# My Budget Tracker

## Project Description
My Budget Tracker is a simple website designed to help
users record and organize their daily expenses.

## Files Used

### index.html
Contains the structure of the website, including:
- Website heading and logo
- Add Expense form
- Category dropdown
- Expense table
- Budgeting video
- Instructions section

### style.css
Controls the appearance of the website, including:
- Background colors
- Fonts and spacing
- Form styling
- Table borders and colors
- Hover effects
- Advanced CSS selectors

## Features Added in Week 2
1. Expense table with five sample records.
2. Expense form with five category options.
3. Logo image.
4. Embedded YouTube video.
5. Collapsible instructions section.
6. Advanced CSS selectors.
7. Table hover effects.

## Technologies Used
- HTML5
- CSS3
- Visual Studio Code
